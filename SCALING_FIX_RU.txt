ULT Layout Editor — исправление масштабирования окна

Причина: в V4 ширина окна меняла ширину панелей и расстояния между контролами,
при этом координаты элементов из default.xml оставались фиксированными.

Теперь композиция рассчитывается в неизменной системе координат 1320x740 и
масштабируется целиком с сохранением пропорций. Масштабируются также фоновые
панели, контролы, значения, Insert Chain и overlay редактора.

Изменение размера окна сохраняется автоматически в:
%APPDATA%\ULT\Layouts\window.xml

Расположение контролов хранится в:
%APPDATA%\ULT\Layouts\default.xml

Для чистой проверки старого макета временно переименуйте default.xml в
backup_default.xml. Для полного сброса удалите оба XML при закрытом FL Studio.

Сборка на Windows не проверена в этой среде.
