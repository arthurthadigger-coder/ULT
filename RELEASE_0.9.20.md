# ULT 0.9.20 — Layout Editor corrections

- Multi-selection remains active when dragging a selected group member.
- Proportional group resizing preserves the group aspect ratio by default.
- Group drag is clamped to the 1320×740 logical editing canvas.
- Distance guides are hidden during resizing; only dimensions are shown.
- Multiple marquee passes add to the current group selection.
- Failed global layout saves now display an error instead of false SAVED status.

Still pending: scalable text per group, per-instance unsaved colour, stable IDs for dynamic controls, robust cross-instance synchronization, FL Studio/Windows compilation tests.
