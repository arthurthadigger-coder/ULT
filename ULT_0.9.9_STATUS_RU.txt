ULT 0.9.9 — ПРОМЕЖУТОЧНЫЙ ПАКЕТ ИСХОДНИКОВ

Основа: ULT_0.9.0_V7_Bypass_CompileFix.zip.
Изменения в этом пакете:
- Версия CMake изменена на 0.9.9.
- Логотип текстом ULT вместо ult.
- SAVE LAYOUT / RESET LAYOUT / LAYOUT FILE... видны только при Edit Layout.
- EXIT EDIT возвращает сохранённую геометрию при выходе без сохранения.
- Подтверждение перед Reset Layout.
- В меню LAYOUT FILE... доступны загрузка XML и экспорт XML с размером окна.
- Проверка формата и идентификаторов компонентов при импорте.
- Размер окна по-прежнему сохраняется независимо от кнопки SAVE LAYOUT.

ВАЖНО: ЭТО НЕ ПОЛНАЯ РЕАЛИЗАЦИЯ ВСЕХ СОГЛАСОВАННЫХ ИЗМЕНЕНИЙ.
Не реализованы: полноценные новые DSP-визуализации для всех пяти эффектов,
мультивыделение, undo/redo, глобальная синхронизация экземпляров,
новая система акцентного цвета и ряд других пунктов спецификации.
Windows VST3 в этой среде не собирался и не тестировался.
Для проверки исходников на Windows используйте build-windows.bat с установленными JUCE и Visual Studio.
