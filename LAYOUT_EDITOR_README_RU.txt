ULT 0.9.0 — режим редактирования существующего интерфейса

Что добавлено:
- Кнопка EDIT LAYOUT включает слой выбора поверх текущего интерфейса.
- Клик выбирает существующий видимый JUCE-компонент.
- Перетаскивание перемещает компонент.
- Перетаскивание за нижний правый угол (примерно 16x16 px) меняет размер.
- SAVE LAYOUT сохраняет координаты и размеры в:
  %APPDATA%\\ULT\\Layouts\\default.xml
- Макет автоматически загружается при следующем открытии плагина.

Важно:
- Это первый рабочий прототип редактора геометрии существующих компонентов, не полноценный редактор стилей.
- Динамические контролы эффектов существуют только для выбранного эффекта; их layout-сопоставление по типу/порядку может зависеть от состава выбранного эффекта.
- Сложные внутренние элементы ChainView и EqGraph перемещаются как целые компоненты; их внутренние нарисованные элементы отдельно не выбираются.
- Слои/шрифты/цвета/skin не редактируются этим первым этапом.
- Оригинальный интерфейс и DSP не удалялись. Макет хранится отдельно от APVTS и пресетов.

Сборка:
1. Распаковать архив в отдельную папку.
2. Указать JUCE_PATH, если проект не находит JUCE автоматически.
3. Запустить build-windows.bat.
4. Сначала проверить новый VST3 в отдельной копии/папке плагинов FL Studio.
5. Не заменять рабочий ULT до проверки.

Управление:
- EDIT LAYOUT — включить/выключить редактирование.
- Клик по компоненту — выделить.
- Перетаскивание — переместить.
- Перетаскивание за нижний правый угол — изменить размер.
- SAVE LAYOUT — сохранить.

Добавлено: магнитная привязка к краям/центрам других компонентов (порог 8 px); Shift фиксирует движение/изменение размера по X или Y; в EDIT LAYOUT показываются ширина, высота и ближайшие расстояния между компонентами в px.
