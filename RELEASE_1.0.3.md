# ULT 1.0.3 — development snapshot, not a public release

Based on 1.0.2 draft. Added Bitcrush with separate per-voicing parameters, sample-and-hold and quantization, Hz display, migration of legacy saturation settings, explicit 0–200 ms wet Doubler delay, mode-specific protection against oversized SEND geometry, and factory preset extraction on editor initialization. Existing draft changes retained.

Not compiled or tested in FL Studio. Doubler delay changes are not yet smoothed; mode-specific layout persistence needs further work. Still pending: artist presets, bilingual GUIDE, info/welcome/update modals, online update client, modal dimming, toolbar snapping, full compatibility warnings and end-to-end testing. Do not publish.
